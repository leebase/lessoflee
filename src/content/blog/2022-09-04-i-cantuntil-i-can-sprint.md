I didn’t feel up to it but … it’s Saturday, and on Saturday I run intervals.

Sure enough I just wasn’t up to it. Last week I was able to run the first mile without stopping. I didn’t get far at all this time before I needed to walk. I don’t want to be out here.

Do I have to run a 5k? Maybe I’ll just run a mile, I tell myself.

Each interval comes and goes and I start to loosen up. Maybe I’ll run a mile out and back.

If I’m only going so far…why not push myself? Let’s see if I can sprint.

And so I do…I’m running as fast as my arthritic knees can take me. Pumping my arms, huffing and puffing my still obese body down the trail.

And then I walk. And then I sprint again….and then again. The first mile goes by and then the second.

Maybe I’ll keep going and finish the 5k after all. And I do. My best time to date…3 minutes faster than last week.

A year ago I wanted to do HIIT (high intensity interval training) and running sprints is one of the ways to do that. Only I couldn’t run at all, let alone sprint.

Today I could. Today I did. I took running sprints off the list of things I can’t do.
