It’s Saturday, and on Saturday's I run intervals.

Yep, back outside on a gorgeous morning. I really felt like going for a run. Gotta burn off some of that T-Day pie. I felt so good I had thoughts that maybe today would be the day I’d make it all 3.1 miles/5k without stopping.

Wasn’t to be, though I did complete a mile. As I was walking after the first interval I got to wondering how I’d ever do the entire 5k as there is a quarter mile long hill coming up that I’d never been able to run all the way to the top without stopping.

Well, today I did it. I took “run up the tall hill” off the list of things I can’t do. Wasn’t that long ago running itself was something beyond me. Will have to keep working to make the goal of adding “Run a 5k without stopping” to the list of things I can do.

How do I go from arthritic knees that I can’t run on, to arthritic knees that I can? By doing more and going farther.

How much more? A little more.

How far? A bit farther.

Always
