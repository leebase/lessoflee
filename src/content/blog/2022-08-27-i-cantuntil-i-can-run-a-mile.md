Today is Saturday. Saturdays I go run intervals. I was able to run a mile as my first interval. It wasn’t that long ago I couldn’t run at all. I set my sights on being able to run a 5k. I’m reclaiming abilities as I reclaim my health.

It doesn’t happen over night. My journey started 86 weeks ago. I’ve worked on my diet, my exercise, my sleep, fasting and stress management. I’ve put my type 2 diabetes into remission. I can’t say if the osteoarthritis in my knees has healed some or if I’m simply managing better. But I can say I no longer walk with a cane, no longer have a handicap sticker, walk down stairs just fine…and have no interest in the knee replacement surgery my ortho recommended. I no longer take pain meds nor pain creams daily.

I walked when that was all I could do. Then I walked further, then faster as I could. Strength training has also greatly helped.

How far? Just a little farther. How much? Just a tad more. How fast? Just a bit faster.

I completed the 5k today in 42min 30sec. I won’t be setting any world records. I will continue to claw back health and abilities bit by bit. One more milestone added to the list of things I can do.

I can run for a mile without stopping.
