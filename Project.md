# Less of Lee - Project Documentation

## Goal

Migrate **lessoflee.wordpress.com** from WordPress.com to a static, free, and reliable hosting platform.

### Requirements
- **Static site**: No server-side rendering, no database
- **Free hosting**: No ongoing costs
- **Reliable**: Fast, always available, minimal maintenance
- **Content preservation**: All existing posts migrated with images

### Technology Choices

| Need | Solution | Why |
|------|----------|-----|
| Static Site Generator | **Astro** | Content-focused, fast builds, ships zero JS by default, excellent Markdown support |
| Hosting | **Cloudflare Pages** | Free tier, global CDN, automatic HTTPS, Git integration |
| Search | **Pagefind** | Static search, no external service, works offline |
| Content Format | **Markdown/MDX** | Simple, portable, version-controllable |

## Decisions Made

### Comments Strategy

**Decision**: No comments system. Feedback via email.

- WordPress comments will not be migrated (minimal history)
- Footer includes mailto link: `lessoflee@leebase.com`
- Community discussion happens in Facebook groups, not on the blog

### Image Storage

The conversion script will download all images to `src/assets/posts/`. This means:
- Images live alongside code in the repo
- Astro/Sharp will optimize them at build time (WebP, resizing)
- Repo size will increase (potentially 100s of MBs for a long-running blog)

**Alternative**: Store images in Cloudflare R2 or external CDN

**Current decision**: Local storage (simpler, enables Sharp optimization)

## Content Schema

Blog posts require this frontmatter:

```yaml
---
title: 'Post Title'           # Required
description: 'Brief summary'  # Required
pubDate: '2024-01-15'         # Required - publication date (YYYY-MM-DD)
updatedDate: '2024-06-20'     # Optional - last modified date
heroImage: '../../assets/...' # Optional - featured image
---
```

The conversion script automatically:
- Maps `wp:post_date_gmt` → `pubDate`
- Maps `wp:post_modified_gmt` → `updatedDate` (only if different from pubDate)
- Downloads hero images and rewrites paths

## Deployment (Cloudflare Pages)

When ready to deploy:

1. Push code to GitHub/GitLab
2. Connect repo to Cloudflare Pages
3. Configure build settings:
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
   - **Node.js version**: 22 (LTS)
4. Deploy

Cloudflare will automatically:
- Rebuild on every push to the main branch
- Process `_redirects` file for URL mapping
- Serve via global CDN with automatic HTTPS

## URL Continuity & SEO

The conversion script generates `public/_redirects` to handle URL structure changes:

```
/2021/03/my-old-post/ /blog/my-old-post/ 301
/2022/05/another-post/ /blog/another-post/ 301
```

This ensures:
- Old links (LinkedIn, Twitter, search results) don't 404
- Search engines transfer ranking to new URLs
- Readers with bookmarks find their content
